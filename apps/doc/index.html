한글 뷰어 없이 hwp 열고 편집하기 — 업로드 없이 브라우저에서

문서는 한글 프로그램이 없어도 .hwp·.hwpx를 원본 레이아웃 그대로 열어 봅니다. 워드 .docx도 같은 화면에서 열리고, 한글 문서는 본문을 그 자리에서 고쳐 원래 형식으로 다시 저장할 수 있습니다. 문서는 브라우저 안에서만 처리되고 서버로 올라가지 않습니다.

이런 때 씁니다

  • 한글이 깔려 있지 않은 맥이나 회사 PC에서 hwp 파일을 열어 봐야 할 때
  • 공문서·민원 서류로 받은 .hwp의 표와 도장까지 원본 모양 그대로 확인할 때
  • hwp 문서를 인쇄 대화상자로 PDF로 저장할 때

자주 묻는 것

한글 프로그램이 없어도 hwp 파일이 열리나요?
열립니다. 브라우저 안에서 한글 문서 렌더러가 돌면서 표·그림·머리말이 있는 원본 레이아웃을 그대로 그립니다. 한글이나 별도 뷰어를 설치하지 않고 크롬·엣지에서 바로 봅니다.
문서가 서버로 올라가나요?
아닙니다. 파일은 브라우저 안에서만 열리고 어디로도 전송되지 않습니다. 다만 한글 문서를 그리는 렌더러(약 2.1MB)는 이 사이트에서 처음 한 번 내려받습니다 — 파일이 나가는 것이 아니라 프로그램이 들어오는 쪽입니다. 워드 문서는 그것도 없이 열립니다.
hwp를 PDF로 저장할 수 있나요?
"인쇄 · PDF로 저장"을 누른 뒤 크롬 인쇄 대화상자에서 대상을 "PDF로 저장"으로 고르면 됩니다. 변환 서버를 거치지 않고 브라우저가 그린 화면을 그대로 인쇄합니다.

함께 쓰는 도구

인쇄로 만든 PDF를 여러 장 묶거나 순서를 바꾸려면 PDF 합치기를, 문서에서 떼어 낸 그림의 용량을 줄이려면 이미지 압축을 쓰면 됩니다. 표만 따로 다뤄야 하면 엑셀 편집이 있고, 다 만든 문서를 폰으로 넘길 때는 파일 전송이 케이블 없이 기기끼리 바로 보냅니다.

local-tools의 다른 도구 보기 · 모든 처리는 브라우저 안에서 끝나고 파일은 서버로 전송되지 않습니다.
