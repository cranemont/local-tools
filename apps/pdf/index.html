PDF 합치기·페이지 정리·암호 해제 — 업로드 없이 브라우저에서

여러 PDF를 하나로 합치고 쪽 순서를 바꾸거나 지우고 이미지로 바꾸고 암호를 걸거나 푸는 도구입니다. 파일을 고르면 브라우저가 그 자리에서 작업을 끝냅니다. 내려받는 것은 결과 파일뿐입니다. 파일을 올리고 기다릴 필요가 없고 회원가입도 설치도 없습니다.

이런 때 씁니다

  • 여러 개로 쪼개진 계약서·견적서 PDF를 하나로 합칠 때
  • 스캔한 문서에서 잘못 들어간 쪽을 지우고 순서를 바로잡을 때
  • 폰으로 찍은 사진 여러 장(JPG·PNG)을 PDF 한 개로 묶어 제출할 때
  • 첨부 용량 제한에 걸린 PDF를 목표 용량 아래로 줄일 때

자주 묻는 것

PDF 파일이 서버에 올라가나요?
합치기·정리·회전·이미지 변환은 브라우저 안에서 끝납니다. 파일이 네트워크로 나가지 않고 서버에 남는 것도 없습니다. 인터넷을 끊고 써도 동작합니다.
인터넷이 필요하다고 나오는 곳은 어디인가요?
압축·암호 탭의 암호 설정·해제와 용량 줄이기의 “다시 압축”입니다. 셋 다 qpdf 엔진(wasm)을 쓰고 그 엔진 파일을 최초 1회만 외부 CDN에서 내려받습니다. 내려받는 것은 엔진뿐이고 PDF와 입력한 비밀번호는 브라우저 밖으로 나가지 않습니다. 받아온 엔진은 SHA-384 해시가 맞을 때만 실행하고 어긋나면 거부합니다. 용량 줄이기의 “이미지로”는 인터넷 없이 동작합니다.
PDF 용량은 얼마나 줄어드나요?
문서에 따라 다릅니다. “다시 압축”은 글자·글꼴을 그대로 두고 구조와 그림만 다시 압축합니다. 4.19MB 논문 PDF가 3.20MB(76.4%)가 됐고 그림이 큰 2.3MB 문서는 231kB(10.1%)가 됐습니다. “이미지로”는 쪽을 그림으로 다시 그려서 더 줄지만 글자 선택·검색이 사라집니다. 이미 압축된 PDF는 줄지 않고 그때는 원본을 그대로 내려받습니다.
어떤 파일을 넣고 무엇으로 내보낼 수 있나요?
PDF와 JPG·PNG 이미지를 넣을 수 있고 결과는 PDF 한 개로 내보냅니다. 이미지·텍스트 탭은 쪽마다 PNG·JPG·WebP로 만들고 해상도는 108·144·216dpi 중에 고릅니다. 여러 장이면 ZIP 하나로 묶고 한 장이면 그림 그대로 저장합니다. 같은 탭에서 TXT를 고르면 쪽의 글자를 꺼내 문서마다 .txt 한 장으로 저장합니다.

함께 쓰는 도구

PDF로 묶기 전에 사진 용량을 줄이거나 크기를 조절할 때는 이미지 변환·압축을 먼저 거칩니다. PDF에서 뽑아낸 PNG로 움짤을 만들 때는 GIF 만들기로 넘깁니다. 완성한 PDF를 폰이나 다른 PC로 옮길 때는 파일 전송을 씁니다.
