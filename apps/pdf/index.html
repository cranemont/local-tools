PDF 합치기·페이지 정리·암호 해제 — 업로드 없이 브라우저에서

여러 PDF를 하나로 합치고, 쪽 순서를 바꾸거나 지우고, 이미지로 바꾸고, 암호를 걸거나 푸는 도구입니다. 파일을 고르면 브라우저가 그 자리에서 처리하고 결과만 다운로드됩니다. 파일을 올리고 기다릴 필요가 없고, 회원가입도 설치도 없습니다.

이런 때 씁니다

  • 여러 개로 쪼개진 계약서·견적서 PDF를 하나로 합칠 때
  • 스캔한 문서에서 잘못 들어간 쪽을 지우고 순서를 바로잡을 때
  • 폰으로 찍은 사진 여러 장(JPG·PNG)을 PDF 한 개로 묶어 제출할 때
  • PDF에서 필요한 쪽만 뽑아 따로 보낼 때 — 분할·페이지 추출
  • 발표 자료 PDF를 쪽마다 PNG 이미지로 뽑아 쓸 때
  • 명세서 PDF의 비밀번호를 풀거나, 남에게 보낼 파일에 암호를 걸 때

쓰는 방법

  1. 편집·병합 탭에서 [파일 추가]를 누르거나 PDF·JPG·PNG를 끌어다 놓습니다. 여러 개를 한 번에 올려도 됩니다.
  2. 쪽 카드를 드래그해 순서를 바꾸고, 필요 없는 쪽은 [삭제], 돌아간 쪽은 [90° 회전]으로 정리합니다.
  3. 일부만 다룰 때는 카드를 눌러 고른 뒤 [선택 회전]·[선택 삭제]를 씁니다.
  4. [저장 파일 이름]을 정하고 [전체 PDF로 내보내기]를 누릅니다. 고른 쪽만 필요하면 [선택만 내보내기]를 씁니다.
  5. 이미지로 바꿀 때는 [PDF→이미지] 탭에서 화질(빠름·권장·고화질)을 고르고 [ZIP으로 저장]을 누릅니다.

자주 묻는 것

PDF 파일이 서버에 올라가나요?
합치기·정리·회전·이미지 변환은 전부 브라우저 안에서 끝납니다. 파일이 네트워크로 나가지 않고 서버에 남는 것도 없습니다. 인터넷을 끊고 써도 동작합니다.
암호 탭만 인터넷이 필요하다고 나오는데 왜인가요?
암호 설정·해제는 qpdf 엔진(wasm)을 써서, 그 엔진 파일을 최초 1회만 외부 CDN에서 내려받습니다. 내려받는 것은 엔진뿐이고 PDF와 입력한 비밀번호는 브라우저 밖으로 나가지 않습니다. 받아온 엔진은 해시로 무결성을 검증한 뒤에만 실행합니다.
어떤 파일을 넣고 무엇으로 내보낼 수 있나요?
PDF와 JPG·PNG 이미지를 넣을 수 있고, 결과는 PDF 한 개로 내보냅니다. PDF→이미지 탭은 쪽마다 PNG로 만들어 여러 장이면 ZIP 하나로, 한 장이면 PNG 그대로 저장합니다.
PDF에서 특정 쪽만 따로 뽑을 수 있나요?
됩니다. 쪽 카드를 눌러 원하는 쪽만 고른 뒤 [선택만 내보내기]를 하면 그 쪽들만 새 PDF가 됩니다. 여러 PDF를 함께 올려 쪽을 섞어 배치할 수도 있습니다.
무료인가요? 가입이나 설치가 필요한가요?
무료이고 로그인·회원가입·설치가 없습니다. 광고와 사용량 추적도 없습니다. 워터마크가 붙거나 하루 처리 횟수가 제한되지도 않습니다.
어떤 브라우저에서 되나요?
크로미엄 계열 최신 브라우저(Chrome·Edge) 기준으로 만들었습니다. 파이어폭스·사파리는 검증하지 않아 일부 기능이 동작하지 않을 수 있습니다.

함께 쓰는 도구

PDF로 묶기 전에 사진 용량을 줄이거나 크기를 조절하려면 이미지 변환·압축을 먼저 거치면 됩니다. PDF에서 뽑아낸 PNG로 움짤을 만들 때는 GIF 만들기, 완성한 PDF를 폰이나 다른 PC로 옮길 때는 파일 전송을 씁니다.

local-tools의 다른 도구 보기 · 모든 처리는 브라우저 안에서 끝나고 파일은 서버로 전송되지 않습니다.
