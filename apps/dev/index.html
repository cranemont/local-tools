JSON 포맷터·JWT 디코더·텍스트 비교 — 설치 없이 쓰는 개발자 도구

개발자 도구는 JSON·YAML·XML 변환, JWT 디코드, 텍스트 비교, 해시 계산 같은 도구 16종을 한 페이지에 모았습니다. 옆 목록에서 고르거나 검색창에 이름을 쳐서 옮겨 다닙니다. 넣은 값은 브라우저 안에서만 계산하고 서버로 보내지 않습니다. 이 페이지는 외부에 요청을 하나도 보내지 않습니다. 도구를 옮기거나 새로고침해도 넣은 값은 그대로 남습니다. 회원가입도 설치도 필요 없습니다. HTML 파일 한 개로 내려받아 두면 인터넷 없이도 같은 화면이 뜹니다.

이런 때 씁니다

  • API 응답 JSON을 보기 좋게 정리하거나 한 줄로 압축할 때
  • YAML 설정 파일을 JSON으로 바꿔 볼 때 — 반대 방향과 XML도 됩니다
  • 로그인이 안 되는 원인을 찾으려고 JWT 페이로드와 만료 시각을 확인할 때

자주 묻는 것

입력한 값이 서버로 전송되나요?
아닙니다. 16종 모두 브라우저 안에서만 계산합니다. JWT 비밀키·쿠키 값·체크섬을 낼 파일 어느 것도 밖으로 나가지 않습니다. 이 페이지는 외부 서버에 요청을 보내지 않습니다.
인터넷 없이 쓸 수 있나요?
됩니다. 페이지 전체가 HTML 파일 한 개라 홈 화면에서 내려받아 저장해 두면 오프라인에서도 같은 도구가 돕니다. 폐쇄망에서도 파일 하나만 옮기면 됩니다.
JWT 서명 검증도 되나요?
HS256·HS384·HS512는 비밀키를 넣으면 서명 일치 여부를 확인합니다. RS·ES 같은 공개키 방식은 디코드와 만료 확인까지만 되고 서명은 검증하지 않습니다.

함께 쓰는 도구

만든 QR이나 링크를 폰으로 넘길 때는 파일 전송을 씁니다. 스크린샷 용량을 줄이거나 크기를 바꿀 일에는 이미지 변환·압축이 있고 문서를 합치거나 암호를 풀 일은 PDF 합치기에서 합니다.
