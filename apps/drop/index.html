폰과 PC 사이 파일 전송 — 서버·케이블·설치 없이

드롭은 두 기기의 브라우저를 직접 연결해 파일을 옮깁니다. 한쪽에서 만든 여섯 자리 코드를 다른 쪽에 넣거나 QR을 찍으면 연결됩니다. 파일은 중간 서버를 거치지 않고 기기에서 기기로 갑니다. 가입·앱 설치·케이블은 필요 없습니다.

이런 때 씁니다

  • 아이폰에서 찍은 사진을 윈도우 PC로 옮길 때 — 에어드롭이 안 되는 조합
  • 안드로이드와 맥, 태블릿과 노트북처럼 운영체제가 섞여 있을 때
  • 카카오톡 나에게 보내기로 넘기다 화질이 깎이거나 용량에 걸릴 때

자주 묻는 것

파일이 서버에 저장되나요?
아닙니다. 파일은 두 기기 사이 직접 연결(WebRTC)로만 흐르고 어디에도 남지 않습니다. 64KB씩 잘라 데이터 채널로 보냅니다. 브라우저를 닫으면 연결도 끝납니다.
그럼 여섯 자리 코드는 어디를 거치나요?
서로를 찾는 동안에만 공개 릴레이 여섯 곳을 거칩니다. 이때 오가는 것은 연결 정보(SDP)뿐이고 그마저 AES-256-GCM으로 암호를 걸어 올립니다. 코드는 SPAKE2로 검증하므로 릴레이가 코드를 훔쳐봐도 대신 접속할 수 없습니다. 파일은 릴레이를 지나지 않고 기기 사이로만 갑니다.
파일 용량 제한이 있나요?
용량 제한은 걸어 두지 않았습니다. 걸리는 시간은 두 기기의 네트워크 속도가 정합니다. 같은 와이파이에 있으면 공유기 안에서만 오가고 인터넷 구간을 지나지 않습니다.

함께 쓰는 도구

옮기기 전에 용량을 줄이려면 이미지 압축이나 동영상 압축을 쓰세요. 사진에 박힌 촬영 위치를 지우고 보내려면 이미지 도구의 EXIF 제거가 있습니다. 여러 문서를 하나로 묶어 보내려면 PDF 합치기를 쓰면 됩니다.

local-tools의 다른 도구 보기 · 모든 처리는 브라우저 안에서 끝나고 파일은 서버로 전송되지 않습니다.
